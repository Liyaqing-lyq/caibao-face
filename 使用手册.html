财宝儿换脸 · 使用手册

1. 作品介绍

财宝儿换脸是一款以中央财经大学财宝儿为主题的二维实时换脸互动作品。通过双手比框或点击按钮，将镜头中的人脸替换为财宝儿头像，生成带校园主题页脚的合影。头像随人脸的位置、大小和侧倾角度变化。

四款头像参照提供的照片和公开的财宝儿二维形象重新勾绘，按外观分别称为运动、书香、音乐、商务财宝；这些是本作品的分类称呼，不代表官方角色名称。每轮四款各出现一次，顺序随机，跨轮也不会连续出现同款。头像是二维平面贴图，不包含立体建模或表情驱动。

2. 运行条件与启动

- Windows 10/11，较新版本的 Edge 或 Chrome，摄像头；建议电脑运行。

- 安装 Python 3.8 或更高版本，并加入 PATH。无需安装 Python 第三方库、npm 依赖或下载识别资源。

- 完整解压源码包，保留 assets 和 vendor 文件夹。双击 start.cmd，保持启动的终端窗口打开。

- 也可在项目目录打开 PowerShell，执行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1

浏览器打开 http://localhost:8840/ 。不要直接双击 index.html。首次开启摄像头时需加载本地识别组件，请稍候。如果端口被占用，可执行 `python .\serve.py --port 8841 --open`。

3. 体验流程

1. 点击“开启摄像头”，允许浏览器访问摄像头。等待状态变为“本地识别中”。

2. 正对镜头，确保画面里只有一张清晰的人脸。双手各伸出拇指和食指组成 L 形，放在脸的两侧，四个指尖围住脸。保持约 0.7 秒完成换脸。

3. 放下双手至少约 0.6 秒，再比框可换另一款。持续举着同一个手势只触发一次。

4. 也可直接点击“换一款财宝儿”。使用“头像大小”“上下位置”调节遮盖效果。

5. 点击“保存校园合影”，下载 PNG 图片。照片含当前画面与校园主题页脚，不包含手势辅助线。

6. 点击“恢复真人”取消头像，点击“关闭摄像头”结束。页面切到后台也会自动关闭镜头，返回后需重新开启。

快捷键：空格换脸、R 恢复真人、S 保存照片。输入控件获得焦点时快捷键暂停；按钮获得焦点时空格统一用于换脸。

“镜像画面”控制自拍方向；“手势辅助线”只影响预览。“切换前后镜头”主要供有多个前后摄像头的设备使用，单摄像头电脑可能仍选择同一镜头。

4. 拍摄建议与常见问题

情况 · 处理方法

无法启动脚本 · 检查 Python 是否安装并加入 PATH；使用上面的 PowerShell 命令，只为本次启动设置执行策略

摄像头权限被拒绝 · 在地址栏权限设置中允许摄像头；检查 Windows 的摄像头隐私权限

镜头被占用或黑屏 · 关闭视频会议、其他相机页面，重新开启；确认摄像头连接正常

一直提示正对镜头 · 改善正面光照，避免逆光、遮挡和过度侧脸；只保留一个人入镜

手势没有触发 · 双手完整入镜、食指伸直、拇指张开，框包住脸并保持；放下手后再重试，也可使用按钮

头像偏大或偏高 · 使用大小和上下位置滑块；保持正脸并适当远离镜头

动作卡顿 · 关闭占用性能的标签页，使用较新的电脑浏览器；本作品不保证固定帧率

手机通过电脑 IP 无法开镜头 · 摄像头通常要求 HTTPS 或设备本机 localhost；当前服务只监听电脑本机。手机体验需另行部署 HTTPS 站点

照片没有弹窗 · 查看浏览器下载记录和默认下载目录；照片不会自动写入项目目录

四款头像使用透明 PNG，长边约 1030–1054 像素；assets 同时保留可编辑、可放大导出的 SVG。当前版本为参照原形象的二维勾绘适配稿，并非官方原始设计文件，来源见“素材说明.md”。当前支持单人脸；遮挡、快速动作和大幅转头可能影响跟踪。

5. 数据与退出

摄像头画面、关键点识别与照片合成在浏览器本机完成，无麦克风访问，无后端上传。识别资源随包提供；完整包可断网运行。照片只有点击保存后才作为文件下载。退出时先关闭摄像头，再关闭浏览器和启动终端；终端中 Ctrl+C 可停止本地服务。

文件 · 用途

index.html、styles.css · 页面和响应式样式

app.js · 摄像头、识别调度、二维叠加和照片导出

tests/engine.test.js · 轮换、手势门控及坐标逻辑测试

THIRD_PARTY_NOTICES.md · 第三方依赖与素材说明

开发验证需 Node.js 18+，运行 `node --test tests/engine.test.js`。日常体验无需 Node.js。已验证识别组件本地加载、随机轮换、模拟关键点手势触发、恢复真人、离开画面重置、合影下载与权限错误提示。实际摄像头下的贴合、识别速度与双手动作效果仍应由体验者现场检验。
